アセン検索ツール
Assembly Explorer, Assembled with Claude
Ver0.80
1説明
希望する条件を満たすアセンを検索するツールです。パネル1～8を順に入力・閲覧して使用します。
パネル説明文の表示：
  • 本ツールはPCやタブレットなどの大きな画面で操作することをおすすめします。スマホでも操作可能ですが少し見にくいかもしれません。
  • パネル2,3,4はアセンを入力してパラメータ(AC SPEC)を表示する機能です。
  • パネル5,6,7,8は検索条件を入れて検索したアセンのパラメータ(AC SPEC)を表示する機能です。
  • パネルタイトル部分をドラッグするとパネル位置を入れ替えられます（マウス操作時）。
  • 各種速度、安定回復補正、EN関係パラメータなど一部のパラメータは0〜2程度誤差があります。
  • 本ツール最新版はこちら → 公開ページ
  • 最終的なアセンは必ずゲーム上で確認してください
アセンの例を以下から選択すると自動で入力できます。本ツールのチュートリアルとして活用する場合はパネル2~8を順番に確認してしてください。

9詳細説明
各種事項の説明です。
  • 連続QB回数：EN容量最大のときに、連続で何回QBをできるか（QBリロード時間を無視するものとする）
    連続QB回数 = EN容量 / QB消費EN
  • EN完全回復時間（通常）
    EN残量が最小の状態から完全回復するまでにかかる時間（焼いていないとき）。
    EN完全回復時間（通常） = EN補充遅延 + EN容量/EN供給効率
  • EN完全回復時間（復元）
    ENを焼ききったときから完全回復するまでにかかる時間。
    EN完全回復時間（復元） = 供給復元遅延 + (EN容量-復元時補充EN)/EN供給効率
  • 供給復元遅延
    ENを焼ききったときから復元時補充ENだけ回復するまでかかる時間
    供給復元遅延 = (2 - ジェネレータ供給補正 / 100) * 1000 / 供給復元性能
  • QB5回回復時間(通常）
    EN残量が残っている状態で、QB5回できるまで回復するのにかかる時間
    QB5回回復時間(通常） = EN補充遅延 + (5 * QB消費EN（実効値）)/EN供給効率
  • 各種攻撃力許容量
    どのくらいの攻撃を許容できるかの目安
    各種攻撃力許容量 = AP / (2 - 各種防御性能/1000)
  • ブースト速度、QB速度、AB速度、ホバー速度
    それぞれの速度は、調査の結果、以下の計算式であることがわかりました。
    各種速度 = 基準値(各種推力等に依存) * 重量補正(重量に依存) * 重量過多補正(重量過多で発生)
  • QBリロード時間
    調査の結果、以下の計算式であることがわかりました。
    QBリロード時間 = 基準値(ブースターのQBリロード時間) * 重量補正(機体の重量がQBリロード保証重量を超えた重量に依存)
    機体の重量がQBリロード保証重量以内であれば重量補正は1です。機体の重量がQBリロード保証重量を超えると、重量補正は1以上に増加します。
  • 安定回復補正
    安定回復補正は重量に依存して決まります。重量110000より軽くなるほどほぼ比例的に上がり、110000より重いとほぼ一定値です。
  • 照準追従性能
    調査の結果、以下の計算式であることがわかりました。
    照準追従性能は = 基準値(腕部の射撃武器適正に依存) * 重量超過補正（腕部積載超過で発生）
  • これらのそれぞれの指標の計算式の詳細は、noteで Lamu AC6 などで検索すると分析した記録を見れます。
  • パネル5の検索条件（AP***以上など）は、条件をより絞ると検索総数が減り、検索時間が短くなります
  • パネル6の固定条件は、検索時間に直接影響します。(任意)の欄を減らすと速く検索できます。特にFCS欄は(任意)にするとFCS違いアセンが大量にヒットするので固定した方が良いです。
  • 固定条件は、武装4部位の他にFCSと、あと何か一つを固定すると検索速度が比較的短く済みます。
  • 頭部を(任意)にすると、見た目に癖がある頭も検索されます。こだわりの頭部がある場合は固定をおすすめします。
  • アセンの数値上の性能に関与が多いのはコアとジェネレータですので、コアとジェネレータは固定しないで検索にゆだねると面白い結果が出ることがあります。
  • 腕部は自分の当て勘でこだわりの腕部がある場合は固定すると良いでしょう。
  • 脚部を(任意)にしてしまうとあらゆる脚部が候補に出てくるのでできれば固定したほうが良いです。
  • まれに「速度400以上に条件指定したのに、あるはずの速度400のアセンが検索結果に出ない」ケースがあります。内部では数値の小数点以下まで扱う都合上起こりえます。できれば速度399以上などと余裕を持たせてください。
  • EN補充遅延、EN供給効率、QBリロード時間は機体の操作感に直結するので、自分にとっての適正値を入れ込むのがベストです。わからない場合は普段使っているアセンの値に近い値にして、それより良くなる程度の条件にしましょう。
  • 結果が100件以上あるときは、結果を各種性能（例えばAP 大きい順）で並び替えて、自分で十分だと判断できるラインがあれば検索条件に組み込み、再検索しましょう。
  • 再検索に時間がかかる場合は、本パネルの「検索方法」タブを参照して検索の条件を再度検討してください。
  • 自分がパネル5の条件で指定していない性能で並び替えると思わぬ発見があることがあります。どこまで指標を攻められそうかなどを見ることもできます。
  • 自分が条件で指定した条件で並び替えると、自分で指定した条件が厳しいのかまだまだ余裕があるのかわかります。
  • 結果が20~30件くらいになってきたら、アセンの傾向を眺めてみるのも良いと思います。経験上、頭違いが多いと思いますので（頭部固定していない場合）、性能に甲乙つけがたい場合は頭で選ぶのも一興です。
  • 上手に条件を決めると結果を10件未満くらいに絞れます。そこから先は一個一個吟味することをおすすめします。
  • 条件を欲張りすぎると、検索結果が０件になります。この場合、自分が設定中の条件（仮に耐弾防御1300以上）を消して検索しなおして、結果で耐弾防御大きい順で並べて出すようにするのも良いです。
  • パネル7の「２軸表示」タブでは、検索結果(例えばAP大きい順50件)の性能を選択して、２軸で比較するグラフが表示されます。丸いマーカーが各検索結果を表し、破線はパネル2のアセンの性能です。トレードオフになる関係の性能の確認などに活用できます。
